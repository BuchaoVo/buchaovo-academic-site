# Contributing

This repository is primarily a personal academic website, but improvements to the reusable template, build workflow, accessibility, or documentation are welcome.

1. Create a focused branch.
2. Keep content changes separate from infrastructure changes where possible.
3. Run `quarto render` before opening a pull request.
4. Do not commit private, embargoed, copyrighted, or personally sensitive research material.
5. For software pages, prefer links to canonical source repositories rather than vendoring unrelated code here.
